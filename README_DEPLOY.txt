Despliegue en el repositorio portfoliojcpp
------------------------------------------
1. Haz una copia del repositorio actual.
2. Conserva la carpeta .git del repositorio local.
3. Sustituye el contenido público del repo por los archivos de esta carpeta.
4. Desde la raíz del repositorio:

   git add .
   git commit -m "Rediseño executive portfolio JCPP"
   git push

5. Si GitHub Pages ya publica desde main / root, no necesitas cambiar nada más.

Prueba local
------------
Desde esta carpeta:

   python3 -m http.server 8000

Después abre:
   http://localhost:8000
